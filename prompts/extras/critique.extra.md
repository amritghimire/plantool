Use these skills. When one is not installed, read its file from the skill list below; skip it only when it is not listed.
For code changes:
- `interrogate` or `ponytail-review`. Keep only findings you can show with a concrete input.
- `council` or `sol-loop` for a second opinion from other models on risky changes.
- `blast-radius` when shared code changed.
- `ponytail-debt` to list the `shortcut:` comments the change left behind.
- `maintain-verification-skill` or `maintain-formal-verification-skill` when code they cover changed.
- `leaving-pr-comments` for the format of the comments you post.
For research or a plan:
- `ponytail` at the ultra level to question scope, and `architect` to check the module shape.
